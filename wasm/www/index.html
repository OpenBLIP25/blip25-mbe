blip25-mbe — the vocoder, running in your browser decode-only wasm

A P25 voice bitstream is fetched, framed, and decoded to 8 kHz PCM entirely client-side by the Rust MBE codec compiled to WebAssembly — then played through Web Audio. No server-side decode, no network round-trip per frame.

Loading WebAssembly…

The bundled sample.bits is an IMBE 7200×4400 stream (rate 0), so leave the selector on rate 0 to hear speech. The other rates are wired up to demonstrate the full decode API surface; pointing them at this IMBE sample will decode noise (wrong wire format), which is expected.

Speech material: Open Speech Repository (https://www.voiptroubleshooter.com/open_speech/), encoded to an IMBE bitstream by blip25-mbe. Decode-only WebAssembly build — the encoder is compiled out.
